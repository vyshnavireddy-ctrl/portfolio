# ✨ Vyshu's Creative World — 3D Portfolio ✨

Welcome to the personal 3D animated portfolio of **R. Vyshnavi**, Computer Science & Engineering student at Narasaraopeta Engineering College.

---

## 🌟 Highlights & Features

- 🌌 **Interactive 3D Lavender Dreamscape**: Custom Three.js background with floating crystal geometric totems, stardust particles, and mouse-reactive lighting.
- 🌸 **Atmosphere Particles**: Sakura petals, glowing stardust particles, and pastel dream bubbles floating in the background.
- ✨ **Sparkle Cursor Trail**: Interactive fairy dust particle trail that follows the cursor across the screen.
- 🎬 **Cinematic Welcome Intro**: Welcoming intro animation screen with audio toggle and smooth transitions.
- 🎨 **Lavender Dream & Midnight Themes**: Seamless toggle between warm aesthetic pastel lavender and sleek midnight dark theme.
- 🤖 **Mini Chibi Companion**: Reactive animated avatar that responds dynamically as you navigate through different sections.
- 🌠 **Magical Wish & Affirmation Modal**: Interactive wishing star modal with animated celebratory confetti.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile browsers with custom responsive layout and smooth scrolling.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, JavaScript (ES6+), HTML5, Vanilla CSS3 (Custom Glassmorphism)
- **3D Graphics & Physics**: Three.js
- **Icons & Effects**: Lucide React, Canvas Confetti
- **Build Tool**: Vite 6

## 🚀 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/vyshnavireddy-ctrl/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.

Or simply double-click **`Start_Portfolio.bat`** on Windows!
